## Download transport note

`github.com` release downloads and Git-over-HTTPS were intermittent/failed through Windows schannel. Downloads used Node's HTTPS stack and, for GitHub release assets, `api.github.com` asset resolution followed by the signed `release-assets.githubusercontent.com` URL. The `fetch.mjs` ledger records the canonical browser URL, resolved URL, byte count, SHA256 and timestamp.
